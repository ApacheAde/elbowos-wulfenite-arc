# Wulfenite Arc

Full-colour Python 3 neon artillery arcade for [ElbowOS](https://x.com/ElbowOS).

Slide an amber siege barrel. Arc tangerine shards through gravity.
Smash drifting magenta chunks and gold cores. Combos stack on a clean streak.

A / D aim. Q / E slide. Space / W fire. R reset.

## Play

```
pip install -r requirements.txt
python3 wulfenite_arc.py --play
```

## Record a 9:16 reel

```
python3 wulfenite_arc.py --record
```

Writes `WULFENITE_ARC_ElbowOS.mp4` (1080×1920, 15s, 30fps, H.264).
